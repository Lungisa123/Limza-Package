### Limza R Packages
Video demo: <https://youtu.be/W6ql2sFEJ5Q>

The **Limza** package provides functions for data analysis and filtering,
    including deleting columns , detecting and removing outliers using IQR method,
    counting observations, and calculating intervals.
The following functions can be found
* delete_col
* ranjer
* outliers

## installing the package
* download the tarball file i.e.file that ends with **tar.gz**

in your R working environment
run the following command 
install.packages("limza_1.0.0.tar.gz")
